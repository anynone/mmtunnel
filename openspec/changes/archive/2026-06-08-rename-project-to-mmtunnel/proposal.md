## Why

The project is being renamed from `mmsocket` / `MM Socket` to `mmtunnel` / `MM Tunnel`. Keeping old names across module paths, package metadata, UI, and docs would make releases and support confusing.

## What Changes

- Rename the Go module from `mmsocket` to `mmtunnel` and update internal imports.
- Rename desktop package metadata from `mmsocket-desktop` to `mmtunnel-desktop`.
- Rename desktop product/UI text from `MM Socket` to `MM Tunnel`.
- Rename the Tauri bundle identifier from `cn.anynone.mmsocket` to `cn.anynone.mmtunnel`.
- Rename default local configuration namespace from `mmsocket` to `mmtunnel`.
- Update documentation, OpenSpec text, and service examples that refer to the old project name.
- Keep tunnel command names, API paths, ports, and protocol behavior unchanged.

## Capabilities

### New Capabilities

- `project-identity`: Defines the canonical project identity, package names, display names, and local namespace.

### Modified Capabilities

- None.

## Impact

- Affects Go module/import paths, desktop package metadata, Tauri configuration, frontend text, local profile defaults, docs, and active OpenSpec changes.
- Existing local profile data under the old `mmsocket` config directory is not automatically migrated by this change.
- Build outputs under `bin/` and generated `desktop/dist/` are not the source of truth and are not renamed directly unless regenerated by verification commands.
